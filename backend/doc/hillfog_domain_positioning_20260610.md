# hillfog Domain Positioning Review

Date: 2026-06-10

This document evaluates hillfog only from the KPI / OKR / BSC / PDCA domain perspective.

Technical migration is assumed to happen on qifu4 / MindScore. This document does not evaluate whether the old Spring / Freemarker implementation should be extended.

## 1. Direct Conclusion

hillfog has modernization value from the domain perspective.

However:

```text
The value is not that BSC is still a strong market keyword.
The value is that hillfog already connected KPI, OKR, strategy structure, reporting, owner views, and PDCA-style improvement actions.
```

Recommended direction:

```text
Do not position MindScore as a BSC system.
Position it as a modern performance operating system.
```

Better product framing:

```text
KPI + OKR + Action + Insight
```

or:

```text
Performance Management / Execution Intelligence / Goal & KPI Operating System
```

## 2. BSC In Modern Product Positioning

Balanced Scorecard is not a strong mainstream SaaS selling point today.

The problem is not that BSC is useless. The problem is that:

```text
BSC sounds old, consulting-heavy, and less attractive to modern SaaS users.
```

Therefore, MindScore should not be marketed or designed as:

```text
BSC + KPI + OKR system
```

Instead, BSC should become an optional strategy alignment model.

## 3. How To Reposition BSC

Old hillfog positioning:

```text
BSC is the main structure.
KPI and OKR are attached to the BSC scorecard.
```

Recommended MindScore positioning:

```text
Strategy alignment is an optional view.
KPI / OKR / Action / Insight are the core operating loop.
```

Mapping:

| hillfog term | MindScore term |
|---|---|
| Scorecard / Vision | Strategy Workspace |
| Perspective | Strategic Theme / Pillar |
| Strategy Objective | Strategic Objective |
| BSC Report | Strategy Alignment Report |
| Perspective Weight | Optional strategy weighting |
| BSC | Advanced strategy model / optional template |

This keeps the useful structure while avoiding a dated product identity.

## 4. What BSC Still Provides

BSC still has domain value when treated as a structure rather than a brand.

Useful parts:

- strategy decomposition
- perspective / theme grouping
- objective hierarchy
- KPI alignment
- weighted roll-up
- organization-level performance view
- executive reporting

Less useful as main product identity:

- BSC terminology
- rigid four-perspective framing
- consulting-style scorecard tables
- making users configure BSC before they can use KPI / OKR

Recommended rule:

```text
Users should be able to start with KPI or OKR without understanding BSC.
BSC-style strategy alignment should be available later as an advanced structure.
```

## 5. PDCA In Modern Product Positioning

PDCA is still useful as a management loop, but the name is old-fashioned for modern SaaS.

Do not remove the concept. Reframe it.

Recommended modern names:

| Old term | Modern product term |
|---|---|
| PDCA | Action Plan |
| Plan | Plan / Proposal |
| Do | Execution |
| Check | Review |
| Act | Adjustment / Follow-up |
| PDCA project | Improvement Initiative |
| PDCA item | Action Item |

Possible product language:

```text
Action Plan
Initiative
Improvement Task
Review Cycle
Execution Loop
```

The underlying loop can still be:

```text
Plan -> Do -> Check -> Act
```

But the UI does not need to expose "PDCA" as the primary label.

## 6. hillfog Domain Strengths To Preserve

The following parts are worth preserving in MindScore:

| hillfog capability | Why it matters |
|---|---|
| KPI formula and aggregation | Makes KPI scoring flexible and stronger than simple manual score entry |
| Frequency-based measure data | Supports daily / weekly / monthly / quarterly / yearly reporting |
| Target / actual / min / max | Supports threshold-based and normalized scoring |
| Management mode | Supports bigger / smaller / quasi KPI semantics |
| Quasi range | Supports "near target is best" KPIs |
| OKR objective and key result model | Gives modern goal-management capability |
| Owner and organization linkage | Required for enterprise accountability |
| Personal dashboard | Makes performance visible at individual level |
| Organization chart style OKR view | Useful for alignment and transparency |
| BSC weighted roll-up | Useful for executive strategy reporting when optional |
| PDCA linkage | Converts performance gaps into improvement action |

The strongest domain loop is:

```text
KPI / OKR measurement
-> report and trend
-> insight
-> action / initiative
-> review
-> next measurement
```

This loop is more valuable than the BSC label itself.

## 7. hillfog Domain Parts Not To Preserve As Main UX

The following should not remain as the main product experience:

- BSC-first onboarding
- old scorecard table report as the primary report
- requiring users to understand BSC terminology before creating KPI / OKR
- exposing too many old management terms in the first-run UX
- treating PDCA as a visible primary module name for every user
- making formula scripting feel required for normal KPI setup

These should be replaced with:

- KPI-first setup
- OKR-first setup
- guided formula recommendation
- modern strategy alignment view
- action / initiative boards
- insight inbox
- plain-language reports

## 8. Recommended MindScore Product Core

MindScore should center on:

```text
Goals
Metrics
Scores
Insights
Actions
Reviews
```

Possible module names:

| Module | Purpose |
|---|---|
| Goals | OKR / objective management |
| Metrics | KPI definition and measure data |
| Score Engine | Deterministic KPI / OKR scoring |
| Strategy Alignment | Optional BSC-like strategy mapping |
| Insights | Signals, risks, trends, LLM summaries |
| Actions | Initiatives, tasks, review loops |
| Reports | KPI / OKR / strategy / action reporting |

This is more modern than:

```text
BSC / KPI / OKR / PDCA
```

Even if the underlying domain still supports all four.

## 9. Honest Evaluation Of hillfog Domain Value

hillfog is not valuable because BSC is trendy.

hillfog is valuable because it already contains:

```text
KPI calculation
+ OKR progress
+ strategy alignment
+ owner / organization relation
+ PDCA-style action follow-up
+ reporting
```

This is a meaningful enterprise performance management foundation.

The right modernization decision is:

```text
Keep the domain thinking.
Change the product language.
Change the UX.
Make BSC optional.
Make PDCA an action loop.
Make KPI / OKR / insight the main path.
```

## 10. Recommended Positioning Sentence

Recommended MindScore positioning:

```text
MindScore is an open-source performance operating system that connects goals, KPIs, strategy alignment, insights, and action follow-up.
```

Alternative shorter positioning:

```text
Open-source KPI / OKR performance intelligence platform.
```

Avoid:

```text
BSC system
Balanced Scorecard SaaS
PDCA management system
```

Those labels are too narrow or dated for the intended modernization.

## 11. Final Judgment

From KPI / OKR / BSC / PDCA domain perspective:

```text
hillfog has clear modernization value.
```

But the modernization should not preserve the old product identity.

Correct strategy:

```text
Use hillfog as the domain reference.
Use MindScore as the new product.
Keep KPI / OKR / Action / Insight as the market-facing core.
Keep BSC as optional strategy alignment.
Keep PDCA as the underlying improvement loop, exposed as action / initiative / review.
```
